How to Configure

Method 1: Set window.MULTILINGUAL_CONFIG before loading the library:

<script>
window.MULTILINGUAL_CONFIG = {
    autoWrap: true,
    autoWrapSelector: '.content',
    debug: true,
    cssClasses: {
        wrapper: 'my-multilingual-text'
    }
};
</script>
<script src="multilingual-wrapper.js"></script>

Method 2: Pass config when calling functions:

wrapMultilingualText('#content', {
    debug: true,
    minSegmentLength: 3
});
