Multilingual

A lightweight library that detects writing systems in mixed-language text and wraps each segment in a <span> so you can style each script with CSS.

What & why

Web pages that mix multiple languages — say English with Korean and Arabic — face a typography problem. CSS font-family applies per element, but a single paragraph might need Noto Sans KR for the Korean parts, a different size for the Arabic parts, and direction: rtl just where the Arabic actually appears. Without per-segment markup, you can't target any of this.

Multilingual walks the DOM, detects each character's script via Unicode property escapes (\p{Script=Hangul}, \p{Script=Arabic}, …), and wraps consecutive same-script runs in <span lang="…" data-script="…" class="ml-…">. Then you target each script in CSS the normal way.

<script src="multilingual.js"></script>
<script>
  // Set defaults and auto-wrap on load
  Multilingual.init({ autoInit: true, selector: '#content' });

  // Or wrap on demand
  Multilingual.wrap('#content', { /* per-call config */ });
</script>

Configuration

Each option does one thing. Click through the side-by-side comparisons to see what changes.

separateSpace / separatePunct / separateNum

By default, spaces and punctuation merge into the surrounding script's span, and digits join the Latin segment. Set any of these to true to give that category its own span with class ml-space / ml-punct / ml-num — useful when you want typographic control (tabular numbers, styled punctuation, visible spaces). Separated categories don't propagate during inheritance, so a stray space next to a separated comma still attaches to the nearest real script.

glyphOverrides

Force specific characters to a script regardless of their Unicode block. Useful for brackets you want rendered in your Latin font even when surrounded by Korean, or for Arabic punctuation that should always group with Arabic.

no override — parens inherit Korean

languageOverrides

Override the BCP-47 lang attribute emitted for a script. Browsers use lang for hyphenation rules, screen-reader pronunciation, and font fallbacks — so a Traditional-Chinese site usually wants zh-TW or zh-Hant, not the generic zh. (Each span below shows its lang in a small label.)

default
量子力学
{chinese: 'zh-TW'}
量子力学

useShortNames

When true (default), each span gets an ml-xx class for easy CSS targeting. When false, only lang and data-script are emitted — use this if you target solely via the data attribute. (The right column has no styling because the demo CSS only targets .ml-xx.)

useShortNames: true
Hello 안녕
useShortNames: false
Hello 안녕

skipElements

Tag names whose contents are skipped during traversal. Defaults to ['script','style','noscript','template']. Add 'code' to leave inline code blocks untouched.

default (code is wrapped)
Inline print('안녕') in prose.

Complex sample

A real-world document — five languages, mixed scripts within paragraphs, nested headings, parenthesized Latin inside CJK, Arabic-Indic digits inside Arabic, and an inline <code> block that should pass through untouched.

Multilingual.wrap('#sample', {
  glyphOverrides:    { '()[]{}': 'latin', '،؛؟': 'arabic' },
  languageOverrides: { chinese: 'zh-CN' },
  separateNum:       true,
  skipElements:      ['script', 'style', 'noscript', 'template', 'code'],
});
